# Transcrições brutas

As transcrições das aulas do mini treinamento "Brecha Viral" vão aqui, uma por
aula (`aula-01.md`, `aula-02.md`, …).

O resumo estruturado que o projeto usa como referência é `../metodologia.md` —
é ele que os documentos numerados citam. As transcrições brutas ficam guardadas
para poder conferir a fonte quando o resumo deixar dúvida.

O curso ainda está em gravação: as aulas seguintes à 3 liberam após o período
de garantia (~2026-09-23). Ao chegarem, atualizar também `../metodologia.md` e,
se mudarem alguma decisão de escopo, abrir nova rodada de alinhamento conforme
`../../10-validacao-e-ajustes.md`.
